# Move to Wake 웹 미리보기

React Native/Expo 미리보기 대신 Node.js 기본 모듈로 실행하는 반응형 웹 UI입니다. 별도 웹 프레임워크나 패키지 설치 없이 실행할 수 있습니다.

## 실행

1. Cursor에서 이 폴더를 열고 **Terminal → New Terminal**을 선택합니다.
2. 터미널에서 다음 명령을 실행합니다.

```powershell
npm run dev
```

3. 브라우저에서 [http://localhost:3000](http://localhost:3000)을 엽니다.
4. 서버를 종료할 때는 터미널에서 `Ctrl+C`를 누릅니다.

`npm start`와 `npm run web`도 같은 웹 미리보기 서버를 실행합니다. 노트북과 휴대폰이 같은 Wi-Fi에 연결되어 있을 때 PowerShell에서 `$env:HOST="0.0.0.0"; npm run dev`를 실행하고, 휴대폰 Safari에서 `http://노트북의-IPv4주소:3000`을 엽니다. IPv4 주소는 `ipconfig`에서 확인하세요. 종료는 `Ctrl+C`입니다. 이 HTTP 미리보기는 화면 확인용이며 위치·모션 센서 권한은 HTTPS 링크에서만 시험할 수 있습니다.

GitHub Pages HTTPS 미리보기는 `main`에 push하면 Actions 워크플로가 배포합니다: <https://sunho772156-cmd.github.io/walking_alarm/>. 로컬에서 배포 파일만 확인하려면 `npm run build:pages`를 실행한 뒤 `dist/`를 확인하세요.

## 화면

- **알람 설정:** 시간 선택, 7m~50m 목표 거리 슬라이더
- **알람 진행:** 브라우저가 제공하는 실시간 속도(m/s)를 시간에 따라 적분한 누적 거리. 앱은 좌표를 읽거나 저장하지 않습니다. 위치 서비스 권한은 속도 샘플을 받기 위해 필요합니다.
- **계정·그룹:** 로그인/회원가입 폼, 그룹 생성, 주간 기록 미리보기
- **센서 확인:** 첫 화면의 **센서 사용 시작** 버튼을 직접 눌렀을 때만 가속도·회전·방향 이벤트 권한을 요청하고 데이터를 수집합니다. 권한 거부, API 미지원, HTTPS가 아닌 경우 안내와 다시 시도를 표시합니다.
- **알람 예약:** 여러 알람을 각각 저장하고 시각순으로 표시합니다. 예약은 이 브라우저의 로컬 저장소에 보관됩니다.
- **알람음:** 프로젝트 폴더의 MP4 전체에서 음원을 추출하면 선택·미리 듣기할 수 있습니다.
- 작은 화면에서는 레이아웃이 모바일 너비에 맞춰 바뀝니다.

브라우저 예약은 페이지가 열려 있고 활성 상태일 때만 동작할 수 있습니다. 브라우저를 닫거나 기기가 절전 상태이면 정해진 시각에 울리지 않을 수 있습니다. 안정적인 백그라운드 알람에는 네이티브 앱이 필요합니다. 이동 거리는 브라우저 위치 서비스가 제공하는 `coords.speed`(m/s)만 시간에 따라 적분합니다. 앱 코드는 위도·경도·정확도 필드를 읽거나 저장·전송하지 않습니다. 다만 이 속도 필드에 접근하려면 HTTPS와 사용자 위치 권한이 필요하며, 속도 샘플은 실내에서 null이거나 부정확할 수 있습니다. 저속 잡음과 비정상 속도, 긴 샘플 공백은 거리에서 제외합니다. 속도 적분은 실제 공간 이동의 완전한 증명이 아니므로 추정치입니다. GitHub Pages에는 사용 권한이 확인되지 않은 MP4/MP3 알람 파일을 배포하지 않으므로, 공개 미리보기에서는 알람음이 비활성화됩니다. 인증·그룹 공유는 미구현입니다.

MP4에서 MP3를 추출하려면 FFmpeg가 PATH에 설치되어 있어야 합니다. MP4 파일을 프로젝트 루트에 넣고 `npm run extract-alarm`을 실행하세요. 성공한 파일은 `assets/alarm_sounds/`에 저장되며, 브라우저 새로고침 후 알람음에서 선택할 수 있습니다. 알라미 공식 콘텐츠는 재사용 권한 확인 후 배포하세요.

## 파일

- `index.html`: 웹 화면 구조
- `style.css`: 반응형 디자인
- `app.js`: 화면 동작, 알람 예약, 센서 데이터 표시
- `speed-distance-tracker.js`: 위치 서비스에서 받은 속도만으로 누적 거리 계산 (좌표 미사용)
- `server.js`: Node.js 내장 HTTP 서버
